# FrameSet – Executable Structural Frame
Version: 1.0
Status: Open Core / Extensible Architecture

## 1. Definition

FrameSet is the execution shell of the Strinum Ecosystem.

It defines how structure becomes executable code.

---

## 2. Core Principles

1. Every execution occurs inside a frame.
2. Frames manage state transitions.
3. Frames are hierarchical containers.
4. Frames expose plugin interfaces.

---

## 3. Architectural Position

SUL → Strinum → FrameSet → Runtime

FrameSet is the bridge between structural definition and code existence.

---

## 4. Open Strategy

FrameSet Core Interface is open.

Advanced runtime optimizations may be licensed.

---

## 5. Plugin Model

FrameSet supports plugin registration:

- Frame lifecycle hooks
- State handlers
- Transition modules

This enables ecosystem growth while preserving core philosophy.
